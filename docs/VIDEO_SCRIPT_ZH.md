# Cursor Atelier 发布视频脚本

建议成片：横屏 16:9，约 4 分钟。画面以屏幕录制为主，配合少量标题卡和放大特写。录制素材请使用自制或明确可授权的 PNG/GIF，不要展示可能有版权争议的角色指针样本。

## 录制前准备

1. 准备一张透明背景 PNG、一张 JPG、一张 4–8 帧的 GIF。
2. 提前下载 GitHub Release 中的 Windows 安装包，并完成 SmartScreen 处理，避免录制中断。
3. 浏览器和 App 都缩放到 100%，隐藏书签栏、通知和私人标签页。
4. 准备一个空白桌面区域，用于展示导出的 `.cur` 和 `.ani` 文件。

## 分镜与旁白

### 00:00–00:12｜开场钩子

**画面**：先快速展示普通 PNG，切到 Cursor Atelier，最后展示生成的鼠标指针在测试区域移动。

**旁白**：

> 一张图片，怎么变成 Windows 真正能用的鼠标指针？这是我做的 Cursor Atelier：不上传文件，不需要账号，图片在本机几步就能导出成 CUR，动画还能导出 ANI。

**屏幕字幕**：`PNG / JPG / GIF → CUR / ANI`、`Local-first`

### 00:12–00:35｜项目定位

**画面**：打开首页，缓慢扫过标题、上传区和“仅在浏览器本地处理”提示。

**旁白**：

> 它不是专业指针编辑器的替代品，而是一个轻量工具。目标非常明确：上传图片、调整画面、设置热点、在本地编码，然后下载 Windows 指针文件。网站没有后端、数据库和账号系统，上传的图片不会离开你的设备。

### 00:35–01:25｜静态指针演示

**画面**：拖入透明 PNG；依次选择 32、48、64；回到推荐的 32；点击画布改变热点；在测试区移动。

**旁白**：

> 先拖入一张透明 PNG。输出尺寸只保留 32、48 和 64 三档，其中 32 像素兼容性最好。图片会保持比例缩放并居中放进透明正方形画布。这里的热点，决定了真正发生点击的位置；可以直接点画面，也可以输入精确坐标。右侧测试区会立即显示效果。

**操作特写**：热点从左上角移动到图案尖端，随后点击“下载 CUR”。

### 01:25–01:48｜像素画与 JPG

**画面**：切换“平滑缩放”，放大展示边缘差异；短暂导入 JPG 并展示不透明背景提示。

**旁白**：

> 普通插画建议保留平滑缩放；像素画关闭后会保持硬边缘。JPG 也能使用，但它本身没有透明通道，所以工具会明确提醒背景不会自动消失。

### 01:48–02:35｜动画指针演示

**画面**：导入 GIF；展示帧条、单帧选择、动画预览、速度选项；分别导出当前帧 CUR 和完整 ANI。

**旁白**：

> 导入 GIF 后，工具会在浏览器中合成局部帧，并正确处理 disposal。你可以预览动画、选择任意一帧导出 CUR，也可以调整全局播放速度，再导出完整 ANI。ANI 使用 Windows 的 RIFF ACON 结构，帧时间会换算成六十分之一秒单位。

### 02:35–03:05｜技术亮点

**画面**：GitHub 代码页快速展示 `encode-cur.ts`、`encode-ani.ts` 和测试文件；不要停留展示大段代码。

**旁白**：

> CUR 和 ANI 编码器是项目自己的 TypeScript 实现，图像处理、格式编码、界面和下载逻辑彼此分离。底层结构有自动化测试，GIF 解码使用 MIT 许可的 gifuct-js。仓库也保留了格式笔记、第三方许可和 Windows 验证清单。

### 03:05–03:32｜Windows App

**画面**：打开 GitHub Releases，下载 `-setup.exe`；启动 Cursor Atelier 桌面版；导出时展示 Windows 原生“另存为”窗口。

**旁白**：

> 除了网页，仓库还提供轻量的 Tauri Windows 版本。它复用完全相同的编辑和编码逻辑，导出时使用系统原生的另存为窗口。安装包由 GitHub Actions 自动构建；因为暂时没有商业代码签名证书，Windows 首次运行可能出现 SmartScreen 提示。

### 03:32–03:52｜开源与隐私

**画面**：README、MIT License、仓库首页与 Release 链接。

**旁白**：

> Cursor Atelier 以 MIT 许可证开源。项目不收集图片，也不负责自动修改系统指针设置。你可以直接使用、学习源码，或者提交问题和改进建议。

### 03:52–04:05｜结尾行动号召

**画面**：回到成品界面，用刚制作的指针划过项目名称；结束卡放仓库名。

**旁白**：

**结束字幕**：`github.com/Ts1ngyun/cursor-atelier`

## 剪辑提示

- 上传、解码和导出等待时间直接跳切，不要让进度停留超过一秒。
- 热点和像素画部分使用 200% 局部放大，让差异在手机端也看得清。
- 所有涉及隐私的画面都只说可验证事实：本地处理、无后端、无账户、无云存储。
- SmartScreen 提示只需解释“未购买代码签名证书”，不要引导观众关闭系统安全功能。
- 简介首行放 GitHub 仓库，第二行说明 Windows 安装包位于 Releases。
